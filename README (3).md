# WOUND-LINK: Community Wound Care and Early Referral Network

Seva First Innovation Challenge 2026 | Theme 3: Swasth & Samavesh Bharat | Track A + B | Puducherry

An offline, nurse-led tool for wound and pressure-injury follow-up. Healthcare workers register a patient by code (no names), record risk factors and wound details, get a referral level (URGENT, REFER, MONITOR or a risk level) and a next review date, and keep a follow-up register on the device. A simple caregiver guide gives warning signs and daily skin-check reminders.

**A follow-up aid only. It does not diagnose or decide treatment. A doctor confirms every referral.**

## Setup
No installation and no environment variables. Open `index.html` in any browser (works offline). Optional hosting: GitHub Pages (Settings > Pages > main branch, root).

## Testing
See `TEST_CASES.md`. Run `runTests()` in the browser console, or follow the table by hand.

## Documentation
`ARCHITECTURE.md`, `TEST_CASES.md`, `LICENSE` (MIT).

## Limitations
Prototype. Review intervals and triggers are defaults that need clinical review. The risk list is a checklist, not a validated scale. Not for use as a diagnostic device.
